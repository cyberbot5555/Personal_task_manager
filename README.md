# Daily Task Manager

A dark, cybersecurity-inspired Windows desktop app for daily tasks, recurring
routines (CSE, SOC, forensics, RE, networking), completion tracking, and
history — built with Tkinter and the Python standard library.

## Requirements

- Windows 10/11
- Python 3.11+

## Install (dev)

```bat
py -3.11 -m venv .venv
.venv\Scripts\activate
py -m pip install --upgrade pip
py -m pip install pyinstaller
